How Eclipse works

Eclipse turns text into tokens, passes them through a stack of Transformer blocks, and outputs a probability for every token that could come next. This page shows the structure of the model that is loaded right now, and where it looks when it reads a phrase you type.

1. Architecture

Every number below is read from the loaded checkpoint's weights, not typed into this page. Parameter counts are the model's own.

2. Attention

Inside each block, attention lets every token look back at the tokens before it and decide how much of each to take in. Each head does this independently. Type a short phrase to see the weights for that exact input.

These are real attention weights, captured from a single forward pass of the loaded model on your phrase. For every block the server checks that these weights reproduce the model's own attention output exactly, and shows nothing if they do not. They are not illustrative.
