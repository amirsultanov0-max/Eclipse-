Each point is one token from Eclipse's vocabulary, placed by the trained token embedding matrix: its position is the token's first three principal components. These are real attention weights, captured from a single forward pass of the loaded model on your phrase. For every block the server checks that they reproduce the model's own attention output exactly, and shows nothing if they do not. They are the same data as the heatmaps on the flat page.

Hover over a token to see what it attends to.
attention weight 01

Tokens sit on a ring in reading order, clockwise from the top. Each line runs from a token to an earlier token it attends to, and particles flow along it from the earlier token into the later one, faster and brighter for larger weights. A token cannot attend to later tokens, so there are no lines to the future.
