# logs/

Everything in this directory is gitignored except this README. The files are
regenerated by training runs and can be large; this note records the facts about
them that the files themselves cannot.

## Known defect: `transformer_grad_norms_10k.csv` step numbering

That file comes from the 10k continuation run, which resumed from
`checkpoints/transformer_best.pt` at step 5,000 and trained steps 5,001–10,000.

Its `step` column reads **1–5000**, because the logging code at the time numbered
rows from 1 regardless of where a run resumed. **Row N is global step 5000 + N**:
row 1 is step 5,001 and row 5000 is step 10,000. The file itself has been left
unedited.

The sibling training log, `transformer_training_10k.csv`, is numbered correctly
(5,250–10,000). `train_transformer.py` now numbers per-step rows by the true global
step for resumed runs. Recorded 2026-09-22.

## Per-step log format

Runs made before 2026-09-22 write `<run>_grad_norms.csv` with columns
`step, grad_norm` at 6 decimal places. Later runs write
`step, loss, grad_norm, batch_starts_sha256` at full float precision, and each run
also writes a `.provenance.json` manifest next to its results file.
